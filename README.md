# 大学生成长网站

> 每天 10 分钟，把认知变成行动。
> 精选认知语录 + 名人访谈 + 政策风口简报。

---

## 这是什么

一个给大学生用的成长类网站。核心不是「把抖音、B站、小红书的内容搬过来」，
而是帮人走完一个闭环：

```
看到好内容  →  理解内化  →  变成行动  →  持续自律
```

所以首页不做成大杂烩，而是**「成长仪表盘 + 精选杂志」**：

- 上方一句**今日认知语录**（大字）+ 右侧**今日自律行动卡**（能直接勾选）
- 中间三列精选：**认知 · 自律** / **名人访谈** / **政策 · 经济 · 风口**
- 底部说明来源与版权，不偷偷搬运

主线是认知与访谈，政策风口只做简报、不抢主线。

## 怎么打开看

**最简单**：双击 `index.html`，用浏览器直接打开。

不需要装任何东西、不需要联网、不需要起服务——这个项目是**纯静态、零构建**的：
没有框架、没有打包编译步骤，一共 8 个 JS/CSS 文件，外加 Day 18 加的一段视频。

⚠️ **有一处例外（Day 17 起）**：首页的「今日热点」要联网才能读（它读云端那份当日热搜快照），
所以线上那个地址比本地双击**多出一块热点**。
**断网时页面其它部分完全不受影响** —— 实测过：统计卡、语录卡、行动项、导航、底栏一样都不少，
热点那块如实说「这次没读到」并给一个重试按钮，**绝不编数据顶上**。

⚠️ **Day 18 加的视频背景也没有例外。** 它是一段 1MB 的视频，网慢或者读不到时
**页面完全不受影响**（实测：把视频请求掐掉，页面照常打开、照常能打卡，JS 报错 0 条）。
视频底下垫着一层深蓝兜底色，读不到时就是**原来那张深色页面**的样子。
网速慢的话先显示一张封面图，不会留黑块。

> 打卡记录存在**你自己这台电脑的浏览器里**（浏览器提供的本地存储），
> 不上传、不用登录。所以换一台电脑、或者清掉浏览器数据，记录就没了。
> 想换电脑也带着，那要等以后上数据库（另一条路，现在不做）。
> ⚠️ **Day 17 划清一条边界**：上云的只有**公开内容**（热搜，Day 18 起还有**内容库那三列**）；
> **你的打卡 / 收藏 / 自己加的行动项，一行都不上云** —— 这条没有例外。

**改文字只动 `data.js`，改样子只动 `style.css`，改「算」的规则只动 `rules.js`，
想调参数只动 `config.js`** —— 四件事互不干扰。
**要换数据从哪来，只动 `cloud.js`（本地那半在 `store.js`）** —— 页面代码一个字不用改。
**要改「从哪张表、取哪些列、怎么排」，只动 `db.js`** —— 上面两层一个字不用改。
**想把视频背景关掉，只动 `hero-video.css` 和 `index.html` 里那两处** —— 详见下面第 3 个坑。

`assets/` 里那几个 JS 文件的**加载顺序不能换**（后面每个一开头就要用前面那个）：

```
（云端 SDK，走 CDN 先引）→ config.js → db.js → cloud.js → rules.js → store.js → data.js → app.js
```

⚠️ `db.js` **必须**排在 `cloud.js` 前面 —— `cloud.js` 一开头就要用 `window.GROWTH_DB`，
顺序反了它会**整体不执行**（页面看起来「什么都没坏」，但云端功能全没了）。

⚠️ **三个坑记在这儿，改 `index.html` 时容易踩**：

1. **注释必须写在 `<script>` 标签外面。** 写成
   `<script src="assets/x.js"></script>  <!-- 说明 -->` 会让浏览器
   把那段注释的开头当成脚本内容，**把后面的标签结构全吞掉** ——
   表现是**线上整页 JS 全不执行、只剩空骨架**，而本地打开却完全正常。
2. **云端那个 `endpoint` 必须和网页自己挂的域名完全一致。**
   服务端按来源精确匹配，对不上会回 `403`，而**浏览器只会含糊地报
   `Failed to fetch`**（看着像断网），极难查。
3. **想让某块「边缘淡出」，用 `mask`，不要给它垫一个带渐变的兄弟元素。**
   Day 18 想给顶栏 / 大标题加暗色托底，试了两种都不行：
   用 `backdrop-filter` 做磨砂 → **元素矩形边界看得一清二楚**，像贴了张膏药
   （因为 `backdrop-filter` 只模糊矩形**范围内**的背景，外面不模糊，直边必然可见）；
   改成纯渐变 → 元素只有几十像素高，**渐变还没走完就被元素边界裁掉**，还是硬边。
   最后把视频自己用 `mask-image` 上下淡出，**根本不存在边界这回事**，问题才消失。

（`style.css` 和 `hero-video.css` 由 `<head>` 引入，不在这条链上。代码文件一共 9 个。）

## 几条自我约束

这几条是刻意的，不是没做：

1. **内容靠手动摘录，不做自动抓取。**
   这一点跟原来的想法不一样，是**查证之后改的**：抖音官方开放接口的能力是
   「用户授权我，我帮他管他自己的数据」，**取不到别人账号的视频数据**
   （要博主本人授权，多数还只对企业开发者开放，视频数据能力当前标注「暂不开放申请」）；
   而这个站是纯静态网页，**也不能在页面里放长期密钥**。
   所以内容是**手动摘录 + 来源标注**：只放**摘要 + 链接 + 来源标注**，
   不搬全文、不搬全视频。完整查证过程见
   [`docs/day12-content-collection.md`](docs/day12-content-collection.md)。
   ⚠️ **一句话例外（Day 17）**：「今日热点」用的是**公开热搜榜**（百度实时热搜，
   经由 60s.viki.moe 这个公开接口），本来就是要给人看、要给人转的公开榜单，
   不是某个博主的原创作品 —— 所以它可以自动同步。
   **摘要类内容（语录 / 访谈 / 政策）仍然一律手动摘录，这条没变。**
2. **没有可核对出处的内容，一个字都不许上页面。**
   更不许「凭印象写一句」然后挂上真人的名字——那是造假，不是收录。
   所以现在页面上明确标着「示例内容」，底部把
   **「当前引用来源」和「计划收录来源（尚未开始收录）」分成两行写**。
   这条也管「读不到的时候」：**读不到就如实说读不到，绝不编一条数据顶上**。
3. **政策条目必须能点到官方原文。** 不自己解读、不替代官方口径。
   现在还是示例，正式收录时每一条都要核对原文并附链接。
4. **不做搜索、不做登录。** 参考的那份建议里提到这两个，但它们会把这个站
   变成「又一个信息聚合器」——那是另一条路，先把成长闭环做扎实再说。
5. **动效克制。** 只有勾选状态和按钮有过渡，没有花哨动画。
   ⚠️ **Day 18 的视频背景是这条的一次让步，但有边界**：
   它是一段真实拍摄的画面，不是「花哨动画」。
   而且**系统里开了「减少动态效果」时，视频直接不播**（只留封面图）——
   这一条是单独为 `<video>` 补的，因为 `style.css` 里那句
   `prefers-reduced-motion` 只管 `transition`/`animation`，**管不到 `<video>`**。
6. **你的打卡和收藏，仍然只存在你自己的浏览器里。**（Day 17 重申，Day 18 加码说明）
   云端**只存「公开的内容」，你的个人记录一行都没有**。
   ⚠️ **Day 18 起，网页多了一样本事：能往云端写。**（「内容库」那块「新增一条」表单）
   这件事的代价必须先说清楚：**这个站不做登录，所以「能写」的准确含义是
   ——任何打开这个网页的人都能写一条。**
   这是**算过账之后才开的**，不是漏想：
   得到的是「你自己在页面上就能加内容」；换来的是**把门开到刚好够用** ——
   只给新增（不能改不能删）、字段长度卡死、`kind` 和 `media` 限定取值。
   一句话：**管不住「谁来写」，就管住「能写成什么样」。**
7. **背景视频是你自己拍的，不是从网上扒的。**（Day 18）
   这条看起来是废话，但它是这个站「内容必须能核对出处」那条规矩的同一个道理 ——
   用别人的素材，要么注明来源，要么不用。**自己拍的，这两条都不用担心。**

## 技术说明（为什么这么选）

- **纯静态、零构建**：双击就能跑，不挑环境，以后想搬到任何免费托管都容易。
  ⚠️ **Day 17 起有一处例外**：云端 SDK 走 CDN 引入（`<script src="https://cdn.jsdelivr.net/...">`）。
  不引 npm 包是因为那要加一个「构建」步骤，对「双击就能跑」才是真破坏。
  这是 `PRD.md` 硬约束 **C2** 里唯一需要重新说一遍的地方。
- **不用 `type="module"`**：本地用 `file://` 直接打开时模块会被浏览器拦掉、整页白屏。
  所以用传统的 `<script src>` 顺序加载。
- **文字只用 `textContent` 写**：内容里万一出现 `<` `>` `&`，拼 HTML 会让整页错乱。
- **配色收在 CSS 变量里**：想整体换色（比如改成浅色底）只改文件开头那一段。
- **本地数据只有 `store.js` 能碰，云端只有 `cloud.js` 能碰**：两条通道各关在自己的文件里，
  页面代码一个字都不用知道数据是来自本地抽屉还是云端。
  （Day 17 落地的就是这个 —— 「今日热点」走 `cloud.js`，打卡收藏走 `store.js`，
  两者互不干扰，将来要单独换掉哪一边都行。）
- **日期一律用本地时间拼**，不用 `toISOString()`——那个给的是 UTC 时间，
  国内晚上 8 点后会算成「第二天」，打卡会记错日期。
- **前端拿到的云端钥匙本身不带权限**：`endpoint` / `publishableKey` 放在前端代码里是**允许**的，
  它们只负责「标识我是哪个应用」；**真正的权限由服务端按来源（来源域名）校验**。
  长期密钥**永远不会**出现在前端 —— 哪天有个方案要求前端拿一把长期密钥，那个方案就是错的。
- **「网页能写」那道门只开了 INSERT**（Day 18）：
  两张云端表里，`sources` 依然一行都写不进去；`contents` 多了一条 INSERT 策略，
  **UPDATE / DELETE 一个字没给**。策略里的 `WITH CHECK` 把「能写成什么样」卡死
  （长度、取值、`kind`、以及留痕字段不许伪造），再加一条 `UNIQUE (source_id, title)`
  防重复提交。**两道门缺一不可**：只给 GRANT 不给策略、或只给策略不给 GRANT，
  都会得到形似「策略失效」的 `42501`。
- **判「写成功」不能只看「没报错」**（Day 18）：
  RLS 把写入挡住时，PostgREST **不给 error**，只给一个空数组 `data: []`。
  当成成功处理，就会出现「页面说存好了、库里什么都没有」——
  **比报一串错还糟**，因为没人会去查它。所以代码里把空数组判成失败。
- **背景视频用 H.264，不用 H.265**（Day 18）：
  手机拍的视频现在多是 H.265，画质好、体积小，但**浏览器出厂不带 H.265 解码器**
  （要交专利费，厂商默认不装）。所以上传前必须转成 **H.264**。
  症状很具有迷惑性：文件能打开、能播放，**只有浏览器里不动**。
- **背景视频是「纯装饰」，不在 JS 的必经路径上**（Day 18）：
  它不挂 `onerror`，不写任何依赖它的脚本。
  所以视频读不到时，页面顶多少一层画面，**核心功能一个字都不受影响** ——
  这是 PRD 硬约束 **C1**（核心功能不依赖服务器）在视频这一层的落实。
