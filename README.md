# 大学生成长网站

> 每天 10 分钟，把认知变成行动。
> 精选认知语录 + 名人访谈 + 政策风口简报。

---

## 这是什么

一个给大学生用的成长类网站。核心不是「把抖音、B站、小红书的内容搬过来」，
而是帮人走完一个闭环：

```
看到好内容  →  理解内化  →  变成行动  →  持续自律
```

所以首页不做成大杂烩，而是**「成长仪表盘 + 精选杂志」**：

- 上方一句**今日认知语录**（大字）+ 右侧**今日自律行动卡**（能直接勾选）
- 中间三列精选：**认知 · 自律** / **名人访谈** / **政策 · 经济 · 风口**
- 底部说明来源与版权，不偷偷搬运

主线是认知与访谈，政策风口只做简报、不抢主线。

## 怎么打开看

**最简单**：双击 `index.html`，用浏览器直接打开。

不需要装任何东西、不需要联网、不需要起服务——这个项目是**纯静态零依赖**的：
没有框架、没有构建步骤、没有 CDN 引用，就 4 个文件。

---

## 文件结构

```
growth-site/
├── index.html            首页骨架（只有容器，内容由 JS 填进去）
├── assets/
│   ├── style.css         全部样式（配色收在文件开头的 CSS 变量里）
│   ├── data.js           全部内容（语录 / 访谈 / 政策都在这里）
│   └── app.js            把内容画到页面上 + 收用户的点击
└── README.md
```

**改文字只动 `data.js`，改样子只动 `style.css`** —— 两边互不干扰。

## 几条自我约束

这几条是刻意的，不是没做：

1. **不用爬虫。** 抖音 / B站 / 小红书的内容不走爬取，只走官方开放平台或授权转载，
   页面只放**摘要 + 链接 + 来源标注**，不搬全文、不搬全视频。
2. **政策条目必须能点到官方原文。** 不自己解读、不替代官方口径。
   现在还是示例，正式上线前每一条都要核对原文并附链接。
3. **不做搜索、不做登录。** 参考的那份建议里提到这两个，但它们会把这个站
   变成「又一个信息聚合器」——那是另一条路，先把成长闭环做扎实再说。
4. **动效克制。** 只有勾选状态和按钮有过渡，没有花哨动画。

## 技术说明（为什么这么选）

- **纯静态、零依赖**：双击就能跑，不挑环境，以后想搬到任何免费托管都容易。
- **不用 `type="module"`**：本地用 `file://` 直接打开时模块会被浏览器拦掉、整页白屏。
  所以用传统的 `<script src>` 顺序加载。
- **文字只用 `textContent` 写**：内容里万一出现 `<` `>` `&`，拼 HTML 会让整页错乱。
- **配色收在 CSS 变量里**：想整体换色（比如改成浅色底）只改文件开头那一段。
