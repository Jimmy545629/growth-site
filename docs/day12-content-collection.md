# Day 12｜内容收录机制：为什么「走官方接口」这条路走不通

> 对应打卡 Day 12。文件：`docs/day12-content-collection.md`
> 对应 `PRD.md` 第 9 节。这是**一次「按规则停下来报告」的记录**（`AGENTS.md` 第 0 条第 3 款）。

## 一、Jimmy 的要求

1. 收录三个账号：
   - 抖音 **韩秀云讲经济** → 政策 · 经济 · 风口
   - 抖音 **学丞晓艳老师** → 认知 · 自律
   - 抖音 **十三邀** → 名人访谈
2. 「可以挑选出播放量高或者点赞收藏量高的视频以及信息」
3. **「内容怎么拿走：走官方接口」**

按规矩，发现要求和实际情况冲突时**先停下来说清楚**，不自己判断。

## 二、查证结果：官方接口拿不到这三个账号的数据

查的是抖音开放平台官方文档（2026-09-27）。**四条，逐条列出原文口径**：

| 官方能力 | 文档实际怎么写的 |
| --- | --- |
| 视频数据管理（获取点赞 / 分享 / 评论 / 播放数据） | 明确标注「**能力改造中，暂不开放申请**」；且说明「**需用户授权**」「针对审核通过的用户开通权限」 |
| 查询特定视频的视频数据 | 参数说明写着：`item_ids` / `video_ids`，「**仅能查询 access_token 对应用户上传的视频**」 |
| 获取作者视频列表 | 要求「视频作者 ID **有授权给**小程序」「**需用户授权**绑定关系」「**仅限企业开发者**」 |
| 按关键词 / 抖音号搜索高赞视频 | 官方**不提供**这类公开接口 |

**三层硬障碍，缺一层都过不去：**

1. **授权关。** 官方接口的数据模型是「**用户授权我，我帮他管他自己的数据**」，
   不是「我采集全平台的公开数据」。要让韩秀云、十三邀给你授权，不现实。
2. **资质关。** 这类能力多数**只对企业开发者开放**，个人开发者申请不了；
   视频数据能力当前还标注「暂不开放申请」。
3. **架构关。** 本项目是**纯静态零依赖**（`AGENTS.md` 第 4 条第 2 项：不许联网、不许 CDN）。
   就算接口能调：
   - 网页里直接放密钥 = **把密钥公开给所有人**（打开源码就能看见）；
   - 浏览器跨域（CORS）也会直接拦掉跨站请求。

   真要调这类接口，**必须有服务器**——本项目现在还没有。

> **一句话**：官方接口是给「我自己账号的运营数据」用的，不是给「采集别人视频」用的。
> 网上那些号称「能查任意抖音号」的服务，走的都是**采集公开页面**（不是官方接口），
> 那既不合规也不稳定，**这个项目不用**。

## 三、定下来的做法：手动摘录 + 来源标注

跟老项目「手动粘贴一条记录」是同一个思路。

**流程**

1. 刷抖音看到这三个账号里一条好的 → 记下 **标题 / 关键观点 / 链接**；
2. 打开网页把这些填进去（以后做一个「新增一条」的小表单，或先手工写进 `data.js`）；
3. 页面上只呈现：**摘要 + 我们自己的提炼 + 原视频链接 + 来源标注（抖音 · 账号名）**；
4. **不下载视频、不搬运全文。**

**为什么这才是对的做法**

- 不需要任何授权、不碰任何接口，**现在就能做**；
- 出处永远可核对 —— 满足硬约束 C4（页面上每条内容都必须能核到原始出处）；
- 真要引用更多内容，走「**找作者要授权**」这条路（私信说明用途），拿到授权的才允许引用。

**技术口子留着**：以后如果有了服务器，再评估「企业开发者资质 + 官方授权」这条路。
**在那之前，收录一律手动。**

## 四、「挑播放量高 / 点赞高的」怎么办

官方接口拿不到互动数据（见上）。在手动路径下，**这一步由人来做**：

- 打开账号主页，用抖音自带的按热度排序，挑前排的；
- 把**当时的点赞数**记下来，写进条目的备注；
- **必须标明「是记录时的数字」**——数字会变，不标时点就是给人错误信息。

## 五、页面上怎么体现「还没开始收录」

这一条是诚实问题，不是排版问题。所以：

1. 顶部保留「**示例内容（版面确认用，非真实收录）**」标记，真实内容上线后才去掉；
2. 底部**分两行写**：
   - `当前引用来源：` 书籍《穷查理宝典》、书籍《原子习惯》…（页面上内容**真正的**出处）
   - `计划收录来源（尚未开始收录）：` 抖音 · 韩秀云讲经济 ／ 抖音 · 学丞晓艳老师 ／ 抖音 · 十三邀
3. 这两行**不许混在一起**——混在一起，看的人会以为页面上的内容已经出自那些账号了。

**为什么不先把三条内容填进去冒充一下**：
内容必须能核到原始出处、能给出链接，才允许出现在页面上。
凭印象写一句「韩秀云说……」再挂上她的名字，等于**替真人说话**，是造假，不是收录。
所以在这三条来源真正拿到可核对的原文之前，它只是「计划」。

## 六、还需要 Jimmy 确认的两件事

1. **三个账号的抖音号（唯一 ID）。**
   抖音上同名号、搬运号很多，光凭昵称可能收错人。需要那串字母数字才能精确定位。
2. **「学丞晓艳老师」这个名称请再核对一遍**——是「晓艳」还是「晓燕」、
   是不是「学丞」机构旗下的号。名字对不上，来源标注就是错的。
